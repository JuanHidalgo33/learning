## How to run

**Python:** open a terminal in the project folder and run the file:

    python guess_the_number.py

**C#:** requires the [.NET SDK](https://dotnet.microsoft.com/download). From the `csharp` folder:

    dotnet run

**JavaScript / HTML:** open `index.html` in the browser. For JavaScript exercises, check the output in the browser console (`F12`).
